# Minimal Unified World Manager Storyboard

Status: exploratory visual reference; not an approved implementation design.

Date: 2026-07-26.

Related doctrine:
[Direct World Manager Agent-World And Unified UX Spec](../../../DIRECT_WORLD_MANAGER_AGENT_WORLD_AND_UNIFIED_UX_SPEC.md).

## Purpose

Test one complete planning interaction through a minimal, persistent
World Manager-governed communications plane:

```text
calm world
  -> semantic routing
  -> Project Manager response in the unified conversation
  -> parallel World Manager reconciliation
  -> same-context semantic zoom and admission
  -> canonical implementation contract and execution start
```

## Frames

1. [Calm resting world](./01-calm-resting-world.png)
   - one conversation, quiet global posture, focused/background/inactive project
     awareness
2. [Semantic routing](./02-semantic-routing.png)
   - project/task settlement and truthful Project Manager routing without a
     second chat
3. [Project Manager response](./03-project-manager-response.png)
   - immediate project-scoped response plus a provisional `PlanProposal`
4. [World Manager reconciliation](./04-worldmanager-reconciliation.png)
   - candidate registration and unresolved admission decisions after the
     response is already visible
5. [Semantic zoom and admission](./05-semantic-zoom-and-admission.png)
   - provenance/governance inspection and evidence remain visible beside the
     candidate and admission boundary
6. [Contract and execution](./06-contract-and-execution.png)
   - canonical plan, linked implementation contract, and active WorkThread
     without presenting activity as completion

## Stable Visual Invariants

```text
58/42 unified-conversation / project-awareness split
deep-navy communications body
warm-ivory project and semantic-anatomy surface
one global composer
one event lineage
no separate Project Manager chat
candidate != canonical
activity != success
evidence and governance before admission
background and inactive projects remain perceptible but quiet
```

## Generation Posture

Generated with the built-in image-generation path.

Frame 1 used the earlier Editorial Cockpit and Project Constellation mockups as
topology and visual-language references. Frames 2–6 used the immediately prior
frame as a reference and changed only the semantic interaction state. The
sequence is intended to preserve layout identity while testing progressive
semantic transparency.

The images are raster design references. Text, geometry, spacing, and component
details remain exploratory and must be translated into a governed surface
projection before implementation.
